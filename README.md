# Tarkov 查价 · 市场排行生成器

自带数据：启动自动检测资源，缺了自动下载；平时用一个查价小窗搜物品、看均价和7 天价格曲线；
需要排行报表时点一下顶部按钮。单文件 exe，双击就能用，不装运行库、不需要 Python。

## 用法

双击 `TarkovMarketInfo.exe`：

1. **自动检测资源** —— 没有物品数据或图标就自动下载（全程零点击，有进度条）
2. **进入查价小窗** —— 顶部大输入框**输入 2 个字就自动查**，不用回车也不用点按钮
3. 候选出来后按 **上下键**（小键盘和主键区都行）切换选中，回车直接看第一个
4. 详情里有：**24 小时均价**、**商人回收价**、**24h 价格区间**、**近 7 天价格曲线 + 涨跌%**，
   以及各商人分别的收购明细和挂单条数；右上角可**收藏**
5. 搜索框右边有 **「我的收藏」**，可以回看收藏过的物品和最近搜过的词
6. 想出排行报告 → 点顶部绿色按钮 **「打开排行报表」**，选条件 → 开始生成

**所有东西都在 exe 所在的文件夹里**，并且按类型分好了子文件夹，
整个文件夹拷到别的电脑也能直接用：

```
TarkovMarketInfo.exe
data\                      数据与配置
  tarkov.db          ← 物品索引（自动下载 / 「数据与设置」里更新）
  history.db         ← 曲线本地缓存（1 小时有效）
  config.json        ← 界面配置
  preferences.json   ← 查价收藏与最近查看
  error.log          ← 出错时的堆栈（没有就正常，说明没出错）
icon\*.webp        ← 物品图标（约 5470 张，15MB）
reports\                 ← 生成的报表都在这儿
  Tarkov排行_*.html / *.png / *.csv
```

目录名在源码里只有一处定义（`src/data.py` 的 `DATA_SUBDIR` / `ICON_SUBDIR` / `REPORT_SUBDIR`），
要改位置改那三个常量就行，别在别的文件里拼路径。

## 查价

搜「m4a1」「消音器」「显卡」都能搜到，点候选立刻出结果：

| 数字 | 含义 |
|---|---|
| **24 小时均价** | 跳蚤市场 24 小时统计价（本地数据，瞬时出） |
| **商人回收价** | **卖给商人**能拿到的最高价，不是买入成本 |
| **24h 价格区间** | 24 小时内最低价 ~ 最高价 |
| **曲线** | 近 7 天走势 + 涨跌百分比（后台联网补，约 1~2 秒） |

本地没有价格数据时会显示「暂无均价」，不会崩。曲线如果网络不通，会明确提示失败而不是一直转圈。

选候选有三种方式：**上下键**（小键盘和主键区都行，到头停住不循环）、鼠标点击、回车直接看第一个。
自动检索**不会**替你默认选中某一行 —— 打字打到一半就跳详情、顺带拉一次曲线会很烦，
选中哪一行由你自己决定。

支持的搜索：中文名、英文名、拼音缩写、同义词（显卡→显示卡、子弹→弹药、护甲→防弹衣、急救→急救包…）。
搜索是**纯本地**的，5476 项里扫一次只要几毫秒，不联网。

小窗顶部的 **「数据与设置」** 里管三件事：游戏模式（PVE / PVP）、本地数据占用、更新数据与取消。

## 更新数据

- 数据来自 `json.tarkov.dev`（公开接口，不需要 key）
- 图标走**图标包**：从 GitHub Release 一次拉 `icon.zip`（约 16 MB / 5300 张），
  比逐个下 5000 多次稳得多，也不容易被图床限流；然后联网只补齐包里没有的几十张
- 图标包**镜像优先**，镜像都失败才回原始 release（`github.com` 在部分网络下直连不通）；
  解压过的会记在 `icon/.iconpack`，线上包大小没变就不重复下载
- 数据是**全量覆盖**写入 `tarkov.db`；先写临时文件再原子替换，中途失败不会把已有的库写坏
- 全程后台线程，界面不卡；进度和日志在进度窗与「运行记录」里，可中途取消
- 图床被限流时会**主动收手**（连续失败到一定次数就停），过一会儿再点一次会接着补
- 也可以不联网：在「数据与设置」里手动指定一个已有的 `tarkov.db`

## 界面风格

配色和控件风格取自 MaiBill（小睦记账）的「褪色薄荷」设计系统 v2.4：

| 用途 | 值 |
|---|---|
| 窗口底 | `#E9ECE5` |
| 卡片 | `#FFFFFF` |
| 输入底 / 轨道 | `#EDF0EA` |
| 正文 | `#1B2A21` |
| 主色（按钮 / 选中） | `#2E9C74` |
| 深主色（悬浮 / 按下） | `#195E49` |
| 警示琥珀 | `#C08A2E` |

原稿的次要文字色（`#79857C` / `#A9B3AB`）放在白卡片上对比度只有 3.8 / 2.2，
中文小字发虚，所以按 WCAG 压深成 `#5C6960` / `#7B867D`。
界面固定浅色（白底为主），不跟随系统深色主题；深色配色只在开发 / 截图时用 `--dark`。

控件全是 Canvas 手绘（`src/widgets.py`）：圆角卡片、圆角按钮、勾选框、
分段选择器、进度条、状态胶囊。**注意**：tkinter 的 pack 不会把太宽的控件缩回去，
只会让它溢出，所以 `main.py` 里带了 `audit_layout()` 做布局自检（见下）。

界面在 125% / 150% 缩放下会跟着变：启动前声明 DPI 感知（Per-Monitor V2），
所有尺寸按 `设计稿 × DPI倍率 × 0.88` 换算。

## 数据是怎么来的

`src/sync.py` 打的是 `json.tarkov.dev` 的公开 REST 接口：

| 请求 | 用途 |
|---|---|
| `GET /{mode}/items` | 全量物品 + 24h 价格 + 商人买卖价 + `changeLast48h*`（涨跌）+ `types` + `iconLink` |
| `GET /{mode}/items_zh` | 中文名映射表 |
| `GET /{mode}/traders` | 商人 id → 显示名 |
| `GET /{mode}/prices/{item_id}` | 查价曲线（7 天） |

`mode` 为 `pve` / `regular`（PVP）。图标优先走 GitHub Release 上的图标包
（`OatmeaILL/tarkov-mcp` 的 `icons` 标签，镜像优先、失败回原始地址），
包里没有的再按 `iconLink` 逐张补；已有文件跳过。

**换图标包**：把新 zip 传到同一个 release（同名资产覆盖）即可，程序比对线上大小后会自动重下，
不用改代码、也不用删标记文件。

用标准库 `urllib` 而不是 `httpx`：原来的实现只是简单 GET，没用到连接池 / 重试 / 代理，
带上 httpx 只会让单文件 exe 再多几 MB。

写库沿用查价 MCP 的扁平表结构（`items` + `meta`），`sell_json` 存的是
`{"商人名": 最高收购价}` 字典 —— 读端 `best_trader_price()` 按这个格式解析，改结构会读不出来。

**涨跌口径是 48 小时**，不是 24 小时 —— Tarkov.dev 只提供 `changeLast48h`，
所以界面和报告里都标 `48h`。

## 排行报告

「打开排行报表」后可以：选排序口径（均价 / 24h 最低 / 24h 最高 / 挂单数 / 涨跌幅 / 跌幅）、
填关键词、设最低挂单数与价格区间；勾了「48h 涨跌榜」会在报告右下角出一个可拖动的小窗；
顶部「物品类型」下拉可以在 15 个大类之间切（一次渲染 17 张表，切换靠显示/隐藏，不重排）。

输出 HTML 报告、PNG 长图、CSV 三样，可以勾选任意组合。

## 长图是怎么出来的

**不依赖浏览器**：`src/capture.py` 直接用 PIL 排版绘制。
标题区、表头、排名（前三名上色）、物品图标、中英文名、排序口径对应的价格、
24h 区间、挂单标签、页脚说明 —— 全部自己画，1200px 宽，几秒出图。

为什么不用无头浏览器截图：Windows 上 `msedge.exe` 只是个转发器，用户自己开着浏览器时，
新进程会被已有实例接走，`--screenshot` 静默失败（**返回码还是 0**，没有任何报错），
截图文件要么几秒后才落盘、要么干脆不出来。依赖它就会变成"点了生成没反应"。
内置绘制没有这个不确定性，也就不需要 Edge / Chrome。

图里的配色和 `report.py` 的 HTML 报告保持一致（同一个暗色军绿 + 金色系）。

## 自检

```
TarkovMarketInfo.exe --selftest        跑完整链路，结果写 %TEMP%\tarkov_selftest.txt
TarkovMarketInfo.exe --selftest 100    顺便压测 100 条的长图
TarkovMarketInfo.exe --sync pve        不弹窗口同步一遍数据，结果写 %TEMP%\tarkov_sync.txt
python src\main.py --shot a.png --light  截一张界面图（开发用）
```

自检会覆盖：目录布局 → 读库 → 降序/升序检索 → 生成 HTML → 渲染长图 →
**查价搜索与取价** → **查价主窗口（自动检索门槛 / 防抖 / 回车默认选中 / 上下键切候选）** →
**报表窗口 + 同步移交状态 + 资源检测** → **默认输出目录在 reports\ 内**。
`--sync` 用来确认打包后的环境里 HTTPS 能通、数据和图标能落盘。
