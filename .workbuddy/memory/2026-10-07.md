Tarkov 市场排行生成器：读本地 tarkov.db（Tarkov.dev 物品索引，自建），

  src/        源码 13 个

### 核心设计：目录名的唯一真源在 data.py
新增 `DATA_SUBDIR/ICON_SUBDIR/REPORT_SUBDIR` + 五个文件名常量 + 配套函数
`data_dir() / icon_root() / reports_dir() / config_path() / history_db_path() /
error_log_path() / ensure_dirs()`。
**规则：别在别的文件里拼路径**，v1.2 之前到处 os.path.join(app_dir(), ...) 这次全收回data.py。

### ⚠️ 最易踩的坑：参数语义变了
`prefs.*` / `price.*` / `BootChecker` / `SettingsWindow` 收的都是 **data 目录**，不是 exe 目录。
传错成 `data.app_dir()` **不报错，但文件写到 exe 旁边**，很难发现。
HomeWindow 里同时有 self.app_dir（窗口定位用）和 self.data_dir（给 prefs/price）。
AppShell 里两个都有。批量改名时用 python脚本 replace，比逐个 Edit 快。

### 老位置兼容
`data.db_candidates()` 保留 v1.2 的 `app_dir()/tarkov.db` 和更老的 `cache/db/tarkov.db`，
老用户升级不用重下；新数据一律写 `data\tarkov.db`，下次更新自然迁移。

### 本轮踩的坑
1. **docstring 里单反斜杠**：`data\ 子目录` 触发 SyntaxWarning，Python 3.12+ 直接 SyntaxError。
   docstring 里一律用正斜杠
2. **PyInstaller --add-data 用相对路径**：相对路径按 **spec 所在目录**（build\）解析，
   写 app.ico 会去找 build\app.ico 报 Unable to find。必须绝对路径
3. **PyInstaller 输出目录跨盘**：--distpath 指到 C: 而项目在 E:，
   报 ValueError: path is on mount 'E:', start on mount 'C:'。distpath/workpath 要同盘
4. **cmd.exe 被 Bash 调用会被安全策略拦**，build2.bat 里有 pause 也会挂住，
   直接跑 PyInstaller 命令更省事

## v1.3 交互改进：输入即搜 + 上下键选候选（接上文）

用户要求：「查价的时候应该输入到 2 个字符以上时则开始自动检索，不需要按按钮和回车！
然后搜索结果出现时 可以快捷的使用小键盘的上下键切换选中」

### 改动（只动 src/home.py + src/main.py 自检）
- 新增常量 `MIN_SEARCH_CHARS = 2`、`SEARCH_DEBOUNCE_MS = 180`
- `on_query_changed` 挂在 `StringVar.trace_add("write")`
- 新增 `clear_candidates()` / `reset_detail()` / `on_move_selection()`
- 上下键绑在 **Entry 上**：`<Up> <Down> <KP_Up> <KP_Down>`

### 三个关键设计决定（改之前要想清楚）
1. **用 trace_add 不用 <KeyRelease>**：后者漏掉鼠标粘贴；更要命的是**中文输入法**
   ——拼音字母阶段<KeyRelease> 就触发，会拿 "xiao" 搜出乱东西。trace 只在内容真变时触发。
2. **不够 2 字立刻清空，不等防抖**：删字要马上干净，统一走防抖会有 180ms 滞后感。
3. **自动检索不自动选中第一行**：自动和手动走同一个 on_search()，
   **靠 `event is not None` 区分**——只有回车/按钮才 select_candidate(0)。
   否则打字打到一半突然换详情+ 多拉一次曲线。

### 踩的坑
- 自检里 `on_search()` 改成了不自动选中，导致原来自检读到的「详情均价」变成 `—`。
  修法：自检里显式 `on_search(event="selftest")`。**这类"改了交互但自检依赖旧行为"的坑要主动查**。
- 上下键**不能 bind 到窗口**：会和 ScrollArea 滚动抢事件。挂 Entry 上。
- 边界停住不循环；selected_row == -1 时第一次按键落第 0 行（不管按上还是下）。
- `on_move_selection` 只 select，**不调 prefs.record_visit** —— 翻候选不等于"查看"。
- `show_id_list`（我的收藏/最近查看）清掉了 current_query，否则点候选记历史时
  会把 id 列表当成查询词记下来。
